# 本地图纸命名与编号规律（2026-11-16 样本扫描）

基于 J:\局域网文件备份\HK-PC\工作文件\胡凯2025年文件\图\ 下
施工图 414 个、竣工图 562 个 DWG 的实测统计，供配对与编号识别参考。

## 1. 工程编号格式

竣工图文件名开头是单项工程编号，实测格式：

| 格式 | 样例 | 数量占比 |
|---|---|---|
| 2字母+2数字+1字母+3数字 | NC25E096、IC24A016、ID25H023、NC25F009 | 大多数 |
| 2字母+2数字+1字母+2~3位 | NC24EA15、NC24EA86 | 少量 |

编号前缀分布（竣工图 562 个）：
NC25(155)、IC24(144)、IC25(128)、ID25(62)、NC24(28)、IE25(13)、ID24(10)、
VX25(9)、NC23(5)、ID23(1)、IE26(1)。即前缀不固定，不要写死 NC。

`project_code()` 用宽松正则 `([A-Z]{2}\d{2}[A-Z]?[A-Z0-9]{2,4})` 实测命中 561/562。

## 2. 竣工图 vs 施工图的关键差异（配对要点）

- **竣工图**：556/562（99%）文件名带标准编号，格式统一 `<编号>-<工程名>.dwg`，
  是单项工程划分、编号、名称的**唯一基准**。
- **施工图**：仅 28/414（约 7%）文件名带标准编号，绝大多数**没有编号**，
  命名杂乱（"校审核-""（打印）""审+(S)"等前缀，或以工程名开头）。

**因此配对必须以竣工图编号为准**：
1. 施工图文件名含相同编号 → 直接匹配（优先级最高，但覆盖有限）；
2. 文件名不含编号时 → 用竣工图工程名关键字匹配（工程的中文名是更可靠的桥梁）；
3. 一个施工图 DWG 含多个工程图纸 → 用编号/工程名定位布局，或 pairs.json 指定 sj_layout。

## 3. 一图多工程的常见形态

- 编号对：`NC25E121-ID25E043工程名.dwg` —— 一个工程同时有 E（室外）与 H（配套）两个编号。
  以竣工图主编号为准，不要因第二个编号拆成两个工程。
- 合同号干扰：`(NJJX-DD25-0081-FP-001)` 是设计合同号，**不是工程编号**，不可用于配对。
- 施工图里的"编号"有时是审图号/图号，与竣工图工程编号不是同一体系。

## 4. 配对策略建议

以竣工图为锚点逐个处理：
1. 提取竣工图工程编号 A 和工程名关键字 B；
2. 施工图目录中，文件名含 A 的优先；否则含 B 的；
3. 若一份施工图 DWG 有多个布局，逐个检查布局名是否含 A 或 B，命中者为该工程对应图纸；
4. 仍无法确定 → 让用户在 pairs.json 用 `sj_layout` 显式指定，不猜测、不混拼。
