# A4 分幅尺寸判定标准与清晰度保障（2026-11-16 样本实测）

基于 J 盘 18 张不同尺寸施工图样本 + 各尺寸 PDF 切割验证得出。

## 1. 样本发现（为什么不能写死 A1）

实测 18 张施工图的布局名义纸张分布：

| 名义纸张 | 数量 | 说明 |
|---|---|---|
| A4 (210×297) | 8 | 小图，直接就是 A4，无需切割 |
| A3 (297×420) | 6 | 中图，切 2 张 A4 |
| A2 (420×594, User66) | 1 | 切 4 张 A4 |
| Letter (216×279) | 1 | 近 A4，1 张 |
| 空/0×0（无名义纸） | 7 | **布局块为空，实际内容在模型空间** |
| 自定义大幅面 (1496×851 等) | 少数 | 须按实际尺寸判定 |

**结论**：不能假设图纸都是 A1。必须按导出 PDF 的实际页面尺寸动态判定。

> 注：多个样本的"布局块实体数=0、名义纸 0×0"，说明出图内容在模型空间，
> 靠 `PlotType=1`（范围）打印。这进一步说明——判定依据应是**导出后的 PDF 页面尺寸**，
> 而不是 DWG 里的布局名义纸张设置。

## 2. 尺寸判定标准（核心算法）

`split_to_a4.py::split_spec()` 已实现，规则：

1. **算面积比**：`n = round(页面面积 / A4面积)`
   - A4 面积 = 210×297 mm²（对应 595.276×841.890 pt）
2. **枚举因数分解**：对每个能整除 n 的列数 cols，rows = n/cols
3. **选宽高比最接近 A4 的排布**：比较每种排布下 `单格宽高比` 与 A4 竖向(0.707)、
   横向(1.414) 的对数距离，取最小者，决定每格用 A4 竖版还是横版。

验证结果：

| 源页面 | 张数 | 网格 | 目标 A4 |
|---|---|---|---|
| A1 横 (841×594mm) | 8 | 4×2 | 竖向 595×842 |
| A2 横 (594×420mm) | 4 | 2×2 | 横向 842×595 |
| A3 横 (420×297mm) | 2 | 2×1 | 竖向 595×842 |
| A4 横/竖 | 1 | 1×1 | 保持 |
| A0 横 (1189×841mm) | 16 | 4×4 | 横向 842×595 |
| 自定义 1496×851mm | 20 | 5×4 | 横向 842×595 |

## 2.5 内容边界裁白（内容偏一角时）

实测发现：部分图纸（尤其索引页/目录页）图形只占页面一角，若按整页分幅会切出大量空白 A4，
内容被挤在小块、打印不清。因此切割前先做内容边界检测：

- 渲染 0.5x 缩略图，找灰度 < 200 的非白像素 bbox，映射回 PDF 坐标，四周留 14pt 边距。
- **裁白判定阈值 = 内容面积 / 页面面积 < 0.55**：
  - 显著偏小（如 A3 图上内容只占中间 424×836pt）→ 按内容 bbox 分幅，裁掉外围空白；
  - 内容基本铺满（如 A1 竣工图，占比 > 0.55）→ **仍按整页纸张分幅**，不用内容 bbox。
- ⚠️ 关键教训：若一律用内容 bbox，A1 图因边缘留白会使面积比从 8 降到 7，
  导致设计 7 张、变更 8 张不一致。故必须设 0.55 阈值保护整页分幅。

## 3. 清晰度保障（关键：不缩放）

文字打印清晰的唯一可靠原则：**1:1 矢量平铺，绝不把整张图缩小到一张 A4**。

- 用 `page.show_pdf_page(rect, src, 0, clip=单格区域, keep_proportion=True)`：
  每个 A4 页面只放原图的一个局部，矢量信息原样保留，文字是原始大小的轮廓，
  打印 300dpi 甚至更高都清晰。
- **禁止**的做法：把 A1 整图 `show_pdf_page` 铺到一张 A4（相当于缩小到 1/2.83），
  文字会变成 1/2.83 大小，打印机上必然糊。
- 每个局部块保持原比例；若单格宽高比与 A4 略有差异，`keep_proportion=True`
  会留白边而不拉伸变形——这是正确的，宁可留白不可变形。

## 4. 标注编号

每张 A4 右上角加带白底的黑色编号：设计部分"设计方案1..N"、变更部分"变更方案1..N"。
用 fitz 内置 `china-s` 中文字体（无需外部字体文件，避免 SHX 缺字体导致的乱码/黑块）。

## 5. 判定流程总结

```
导出 DWG → PDF（PlotType=1 范围，字体修复）
   ↓
读 PDF 页面实际尺寸 W×H
   ↓
n = round(W×H / A4面积)  →  枚举因数分解 + 宽高比匹配  →  cols×rows
   ↓
按网格 1:1 矢量平铺切割，每格一张 A4（keep_proportion，宁可留白不拉伸）
   ↓
每张加"设计方案N"/"变更方案N"编号
   ↓
设计在前、变更在后合并输出
```
